Labs

    Strata

    An open-source platform built on STAC: one catalog for raster and vector data, notebooks next to the data, and map visualization in the browser. Everything ships as containers, so an instance runs on a single VM.

    Storage
    Assets in object storage — MinIO (S3), Cloud-Optimized GeoTIFF.
    Catalog
    Items and collections searchable through the STAC API — pgSTAC on PostgreSQL/PostGIS, stac-fastapi.
    Serving
    Dynamic map tiles and GeoJSON features — TiTiler-pgSTAC and a vector API.
    Use
    Browse and preview with STAC Browser, analyse in JupyterHub notebooks.
    Deployment
    One container and repository per service, wired together with Docker Compose behind nginx.

    The repository is not public yet. Until it opens, feedback on the live instance, on STAC modelling or on deployment is welcome by email.
