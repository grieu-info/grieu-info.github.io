    Open source

    Strata

    An open-source platform built on STAC: one catalog for raster and vector data, notebooks next to the data, and map visualization in the browser. Everything ships as containers, so an instance runs on a single VM.

    Architecture

    1. 01 Store MinIO (S3) · Cloud-Optimized GeoTIFF Assets live in object storage.
    2. 02 Catalog pgSTAC (PostgreSQL / PostGIS) · stac-fastapi Items and collections, searchable through the STAC API.
    3. 03 Serve TiTiler-pgSTAC · vector API Dynamic map tiles and GeoJSON features on demand.
    4. 04 Use STAC Browser · JupyterHub Browse and preview in the browser, analyse in notebooks.

    Each service has its own container and repository; Docker Compose wires them together behind nginx.
